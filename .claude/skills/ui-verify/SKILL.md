## 1. Обязательный минимум

Своей сборки у библиотеки нет — всё запускается из проекта-потребителя, `<путь>` — папка
библиотеки внутри него.

```bash
npx tsgo -p <путь>/tsconfig.json --noEmit             # строгие типы библиотеки
node --import tsx --test "<путь>/**/*.test.ts"        # юнит-тесты ядра
node <путь>/tools/check-boundary.mjs                  # импортов наружу нет
node <путь>/tools/check-tokens.mjs <стили проекта…>   # договор темы
```

В socrat короче: `npm run typecheck`, `npm run test:ui`, `npm run ui:build`.

⚠️ Правил глобальный тип — гоняй типы с `--incremental false`: инкрементальный кеш врёт.
⚠️ Добавил значение пропа — прогони генератор утилит, иначе класс молча мёртвый.

## 2. Чек-лист по диффу

- [ ] Импортов наружу папки нет?
- [ ] Новый `var(--…)` есть в `theme/tokens.default.scss`?
- [ ] Респонсив — кортежи, `null` = пропуск?
- [ ] Ни `any`, ни `!`, ни `@ts-ignore`?
- [ ] Покой в `ui.components`, состояния в `ui.states`?
- [ ] Рецепт SCSS взят миксином, а не скопирован?
- [ ] `z-index` токеном?
- [ ] JSDoc у публичных пропов?
- [ ] Публичное не переименовано и не удалено (иначе `BREAKING:` в коммите)?
- [ ] Движение уважает `prefers-reduced-motion`, страховка — `MOTION_END_BUFFER_MS`?

## 3. Вид — в проекте, который этот компонент показывает

Типы и тесты вида не видят.

- Снимок вычисленных стилей до и после (в socrat — `tools/visual-oracle`): пустой diff = вид
  не изменился. Экран, на котором компонента нет, не доказывает ничего — грепни, где он стоит.
- Состояния (наведение, фокус) снимаются ОТДЕЛЬНО: покой их не показывает.
- Проба мёртвых классов — после любой правки, добавляющей значение пропа.
- Клавиатура, перетаскивание и набор текста проверяются руками.
